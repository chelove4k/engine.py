# API скриптов

В этом документе описан API обычных скриптов и компонентов. Для обоих доступны одни и те же объекты движка: `self.GameObject`, `self.Camera`, `self.Mouse`, `self.Keyboard` и `self.GlobalTime`.

## Подключение скрипта к объекту сцены

Создайте Python-файл в `access/scripts`. Имя класса должно совпадать с именем файла, включая регистр. Например, файл `access/scripts/mover.py`:

```python
from pyengine import script, Vector2


class mover(script):
    def start(self):
        self.direction = 1

    def fixed_update(self):
        visual = self.GameObject.Visual
        if visual is None:
            return

        position = visual.position
        visual.position = Vector2(position.x + self.direction, position.y)
```

Подключите скрипт через компонент `scripting` объекта:

```json
"scripting": {
  "scripts": ["access\\scripts\\mover.py"],
  "network": []
}
```

Движок загружает класс с тем же именем, что и файл скрипта. Используйте `start()` для начальной настройки. Не объявляйте собственный `__init__`: движок сам передаёт аргументы конструктору.

## Повторно используемые компоненты

Компонент использует те же методы обратного вызова и объекты движка, что и обычный скрипт, но наследуется от `Component`. Имя класса также должно совпадать с именем файла:

```python
from pyengine import Component


class rotate_on_click(Component):
    degrees = 45

    def on_mouse_click(self, event):
        visual = self.GameObject.Visual
        if visual is not None:
            visual.rotation += float(self.degrees)
```

Добавьте компонент к любому объекту сцены и при необходимости переопределите его значения по умолчанию:

```json
"components": [
  {
    "path": "access\\components\\rotate_on_click.py",
    "properties": {"degrees": 90}
  }
]
```

Каждое свойство доступно прямо у экземпляра компонента (`self.degrees`). Все значения также доступны в виде словаря `self.ComponentConfig`. Имена свойств должны быть допустимыми идентификаторами Python: они не могут начинаться с `_`, совпадать с именами объектов движка или заменять методы.

## Жизненный цикл и время

Движок вызывает следующие методы, если они определены в классе:

| Метод | Когда вызывается |
| --- | --- |
| `start()` | Один раз при запуске скрипта или компонента. |
| `update()` | Повторно, номинально около 120 раз в секунду. |
| `fixed_update()` | При продвижении часов движка, номинально 100 раз в секунду. |

Методы обработки ввода вызываются перед `update()` в каждом цикле скрипта. `fixed_update()` вызывается после `update()`, если часы движка продвинулись. Эти методы не получают аргумент `delta_time`. `self.GlobalTime` — текущее время движка в секундах с момента запуска.

Для каждого подключённого скрипта или компонента создаются отдельный экземпляр и поток выполнения. Храните состояние конкретного скрипта в `self`, а для доступа к прикреплённому объекту используйте `self.GameObject`.

## Объекты, доступные скрипту

| Атрибут | Описание |
| --- | --- |
| `self.GameObject` | Объект, к которому прикреплён этот скрипт или компонент. |
| `self.Camera` | Управление камерой и её именованными целями. |
| `self.Mouse` | Состояние мыши и удобные проверки для этого объекта. |
| `self.Keyboard` | Состояние клавиатуры и проверки отдельных нажатий. |
| `self.GlobalTime` | Текущее время движка в секундах. |
| `self.ComponentConfig` | Словарь `properties` компонента; для обычного скрипта пуст. |

## `GameObject`

У объекта могут отсутствовать некоторые компоненты. Перед использованием проверяйте, что значение не равно `None`.

### `GameObject.Visual`

Если у объекта нет компонента `visual`, значение `Visual` равно `None`. Иначе доступны свойства:

| Свойство | Значение |
| --- | --- |
| `sprite` | Путь к изображению спрайта. |
| `position` | Позиция в мировых координатах в виде `Vector2`. Чтобы изменить её, присвойте новый `Vector2` или кортеж из двух значений. |
| `scale` | Коэффициент масштаба спрайта. |
| `rotation` | Угол поворота в градусах. |
| `alpha` | Непрозрачность: обычно `0` — прозрачно, `1` — непрозрачно. |
| `layer` | Числовой слой отрисовки. Большие значения рисуются поверх меньших; при одинаковом слое поверх рисуется объект, созданный раньше. |

При чтении `position` возвращается значение `Vector2`. Присваивание в `visual.position.x` или `.y` изменит только временный объект. Чтобы переместить спрайт, присвойте новую позицию целиком:

```python
position = self.GameObject.Visual.position
self.GameObject.Visual.position = Vector2(position.x + 5, position.y)
# Можно также присвоить кортеж:
self.GameObject.Visual.position = (position.x, position.y + 5)
```

Изменения этих свойств применяются к объекту в сцене. Например, изменение `visual.layer` обновляет порядок отрисовки и выбор спрайта, который получает ввод мыши при перекрытии.

### `GameObject.Transform`

Если у объекта нет компонента `transform`, значение `Transform` равно `None`. Метод `Transform.overlaps(other)` возвращает `True`, если выпуклый полигон этого объекта пересекается с полигоном другого. В качестве `other` передайте `GameObject` или его `Transform`:

```python
other = self.find_object("name", "wall")
if (other is not None and self.GameObject.Transform is not None
        and other.Transform is not None):
    if self.GameObject.Transform.overlaps(other):
        print("объекты соприкасаются")
```

Полигон задаётся в локальных координатах в поле `transform.polygon` сцены. Для проверки пересечения движок учитывает позицию, поворот и масштаб обоих объектов. Проверку нужно вызывать из скрипта самостоятельно: автоматический метод обратного вызова о столкновении не вызывается.

### `GameObject.Identity` и другие компоненты

Если у объекта нет компонента `id`, значение `Identity` равно `None`. У `Identity` есть поля `name`, `class_`, `type` и `id`. `GameObject.Scripting` равен `None` либо содержит списки скриптов и сетевых подключений объекта. Методы `GameObject.render()`, `remove()` и `register()` отправляют движку соответствующую команду; `register()` возвращает зарегистрированный объект. Вызывайте `register()` для нового экземпляра `GameObject`: объект, переданный скрипту, уже зарегистрирован.

## Поиск объектов

Используйте `self.find_object(by, value)`, чтобы найти первый зарегистрированный объект с компонентом `id`, который подходит под условие. Метод возвращает `GameObject` или `None`, если совпадений нет. Для поиска по слою у объекта также должен быть компонент `visual`.

| Значение `by` | Поиск по полю |
| --- | --- |
| `"name"` или `"n"` | `id.name` |
| `"class"` или `"c"` | `id.class` |
| `"type"` или `"t"` | `id.type` / `object_type` |
| `"layer"` или `"l"` | Текущее числовое значение `visual.layer` |

Пример:

```python
target = self.find_object("name", "tilt_trigger")
if target is not None and target.Visual is not None:
    target.Visual.rotation += 15
```

## API мыши

### Проверка состояния

| API | Результат |
| --- | --- |
| `self.Mouse.position` | Текущая позиция мыши в мировых координатах, тип `Vector2`. |
| `self.Mouse.screen_position` | Текущая позиция мыши в координатах окна, тип `Vector2`. |
| `self.Mouse.is_over()` | Находится ли указатель над спрайтом этого объекта. |
| `self.Mouse.is_over(game_object)` | Находится ли указатель над спрайтом указанного объекта. |
| `self.Mouse.is_pressed(button="left")` | Удерживается ли указанная кнопка мыши. |
| `self.Mouse.was_clicked(button="left")` | Получил ли этот объект подходящий клик с момента предыдущего запроса. |

Названия кнопок: `"left"` (левая), `"middle"` (средняя) и `"right"` (правая). Также можно передать числовой код кнопки.

### Методы обратного вызова мыши

Переопределите любой из этих методов в скрипте или компоненте:

| Метод | Когда вызывается |
| --- | --- |
| `on_mouse_click(event)` | При нажатии кнопки мыши над объектом; вызывается вместе с `on_mouse_press`. |
| `on_mouse_press(event)` | При нажатии кнопки мыши над объектом. |
| `on_mouse_release(event)` | При отпускании кнопки мыши над объектом. |
| `on_mouse_move(event)` | Когда указатель движется над объектом. |
| `on_mouse_enter(event)` | Когда указатель перемещается на объект. |
| `on_mouse_exit(event)` | Когда указатель перемещается за пределы объекта. |
| `on_mouse_scroll(event)` | При прокрутке колеса мыши над объектом. |

`event` — это `MouseEvent` со следующими полями: `position` (мировые координаты, `Vector2`), `screen_position` (координаты окна, `Vector2`), `button` (название кнопки или `None`), `delta` (смещение указателя) и `scroll` (смещение колеса). Также доступен `render_id` — внутренний идентификатор, назначенный движком.

Если спрайты перекрываются, ввод мыши получает верхний видимый спрайт. Приоритет определяется слоем; при одинаковом слое — порядком создания. Для проверки попадания используются границы спрайта, а не полигон столкновения `Transform`.

Пример:

```python
def on_mouse_click(self, event):
    if event.button == "left":
        self.GameObject.Visual.rotation += 45
```

## API клавиатуры

### Проверка состояния

| API | Результат |
| --- | --- |
| `self.Keyboard.is_pressed(key)` | Удерживается ли клавиша. |
| `self.Keyboard.get_pressed()` | `frozenset` с названиями удерживаемых клавиш. |
| `self.Keyboard.was_pressed(key)` | Была ли нажата клавиша с момента предыдущего запроса для неё. |
| `self.Keyboard.was_released(key)` | Была ли отпущена клавиша с момента предыдущего запроса для неё. |
| `self.is_pressed(key)` | Краткая совместимая форма `self.Keyboard.is_pressed(key)`. |

Названия клавиш нечувствительны к регистру; символ `_` удаляется. Например: `"A"`, `"W"`, `"SPACE"`, `"LEFT"`.

### Методы обратного вызова клавиатуры

Переопределите `on_key_press(event)` или `on_key_release(event)`, чтобы получать события клавиатуры. У `event` есть поля `key` (нормализованное название клавиши) и `modifiers` (битовая маска модификаторов оконной библиотеки).

```python
def update(self):
    if self.Keyboard.is_pressed("D"):
        visual = self.GameObject.Visual
        if visual is not None:
            visual.position = visual.position + Vector2(1, 0)

def on_key_press(self, event):
    if event.key == "SPACE":
        print("нажата клавиша пробела")
```

Также доступен `self.get_pressed_keys()`: он возвращает текущее множество нажатых клавиш. `self.get_mouse_clicks()` — низкоуровневый вспомогательный метод для совместимости, возвращающий исходные словари событий мыши. В новых скриптах используйте методы `Mouse` или обратные вызовы мыши.

## API камеры

Цели камеры — объекты сцены с `object_type: "camera"` и полем `id.name`. При запуске скрипта движок выбирает цель. Доступны методы:

| API | Описание |
| --- | --- |
| `self.Camera.switch(name)` | Выбирает цель по имени; возвращает `True`, если она найдена, иначе `False`. |
| `self.Camera.move_camera(dx, dy)` | Сдвигает активную цель на указанный вектор. Также принимает `Vector2` или кортеж из двух значений. |
| `self.Camera.moveto_camera(x, y)` | Перемещает активную цель в мировые координаты. |
| `self.Camera.scale_camera(scale)` | Задаёт масштаб камеры; минимальное значение — `0.01`. |

Методы перемещения возвращают `False`, если активной цели камеры нет. Для совместимости также доступен метод с прежней опечаткой `self.Camera.swich(name)`; в новых скриптах используйте `switch`.

```python
def fixed_update(self):
    if self.Keyboard.is_pressed("W"):
        self.Camera.move_camera(0, 2)
```

## `Vector2`

Импортируйте `Vector2` командой `from pyengine import Vector2`. У него есть изменяемые поля `x` и `y`. Поддерживаются сложение и вычитание с другим `Vector2` или списком/кортежем из двух значений, а также умножение на число:

```python
step = Vector2(2, 0)
next_position = self.GameObject.Visual.position + step
self.GameObject.Visual.position = next_position
```
