# Отчёты прогонов

Архив сырых результатов `tests/stress_test.py` и замеров производительности.
Это не документация API, а снимки метрик на конкретных коммитах и машинах.

| Файл | Что внутри |
| --- | --- |
| `baseline.md` | Сводка baseline-замеров перед рефакторингом |
| `baseline*.json` | Базовые прогоны кэшей, коллизий, регистрации и скриптов |
| `stage*.json` | Контрольные прогоны после этапов рефакторинга |
| `fixed*.json` | Прогоны после исправлений горячего пути |
| `debug*.json` | Диагностические прогоны |
| `after_step*.json` | Замеры скриптовых циклов после отдельных шагов |

## Как воспроизвести

```powershell
python tests/stress_test.py --scenario all --json docs/reports/my-run.json
```

Полное описание сценариев — в [tests/STRESS_TEST.md](../../tests/STRESS_TEST.md).

## Правила

- Имя файла должно говорить, что и когда измеряли: `stage5_all.json` лучше,
  чем `report-final-final.json`.
- Абсолютные числа зависят от машины; сравнивать имеет смысл прогоны,
  сделанные в одинаковом окружении.
- Отчёт без сценария и даты бесполезен: фиксируйте команду рядом с файлом
  или в его имени.
