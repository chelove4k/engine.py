# Документация pyengine

Здесь собраны подробные материалы по движку. Если вы впервые в проекте,
начните с [основного README](../README.MD).

## Навигация

| Документ | Для чего |
| --- | --- |
| [README.MD](../README.MD) | Обзор, быстрый старт, формат сцен, базовый API |
| [SCRIPTING_API.md](../SCRIPTING_API.md) | Полный API скриптов: жизненный цикл, ввод, камера, коллизии |
| [COMPONENTS.md](../COMPONENTS.md) | Компоненты, события мыши и клавиатуры, слои отрисовки |
| [NETWORK_ARCHITECTURE.md](../NETWORK_ARCHITECTURE.md) | Server authority, протокол, предсказание, интерполяция |
| [CODE_GUIDE.md](CODE_GUIDE.md) | Карта исходников: за что отвечает каждый модуль и как идут потоки выполнения |
| [tests/STRESS_TEST.md](../tests/STRESS_TEST.md) | Сценарии и параметры стресс-теста |
| [history/refactor-plan.md](history/refactor-plan.md) | Архив: план упрощения и оптимизации движка |
| [reports/](reports/) | Архив: JSON-отчёты стресс-тестов и baseline-замеры |

## Структура каталога

```text
docs/
├── README.md          этот файл
├── CODE_GUIDE.md      карта исходников
├── history/           исторические планы и решения
│   └── refactor-plan.md
└── reports/           сырые отчёты прогонов
    ├── README.md
    ├── baseline.md
    └── *.json
```

## Правила порядка

- Новые планы, исследования и разборы кладём в `docs/`, а завершённые —
  в `docs/history/`.
- Отчёты стресс-тестов и профилировщика не смешиваем с документацией:
  им место в `docs/reports/`.
- Ссылки на код и команды запуска держим актуальными: документация — часть
  проекта, а не свалка истории.
